# 车机遥控

车机控制、音乐控制、行车记录仪，一套网页 + 两个 App + 手机端。

## 来源与上下游

这套工程里既有自己写的，也有别人写的开源件，运行时还要跟车上已有的 App 对接，所以分三类看：

**上游（别人写的，本仓库不据为己有）**

| 上游 | 是什么 | 许可 | 本工程怎么用 |
|---|---|---|---|
| 车机助手 `com.navi.tool` | 原厂车机应用，百度加固，官方走 mr-mao 域名更新 | 原厂所有 | **不随仓库分发**。构建时自行从合法渠道取得原厂包（`apk/`）并脱壳（`dex/`），两者都已 ignore |
| [xuqian-git/cloudmusic-car](https://github.com/xuqian-git/cloudmusic-car) | 网易云音乐非官方车机客户端，本仓库 `music/cloudmusic-car/app` 的派生源 | LGPL-3.0 | 派生并改造，源码与改动全部在本仓库 |
| [missuo/kumone](https://github.com/missuo/kumone) | 上述项目的上游，提供接口、eapi 加密与应用图标 | LGPL-3.0 | 接口/加密移植，图标沿用上游自带资源，未重绘 |
| 车上既有音源 | 官方网易云车机版或第三方音源 App | 各自所有 | 仅通过 MediaSession / HTTP 控制，**不含其代码** |
| 车机自带行车记录仪 | 原厂设备上的网页服务 | 原厂所有 | 抓它自己的网页做展示，**不含固件** |

**本仓库自己写的（本工程产出）**

| 组件 | 位置 | 作用 |
|---|---|---|
| 注入 dex（网关 + 车控） | `src/bridge/` | 注入车机助手进程，提供 18766 网关与车控 API；原厂代码一个字节不改 |
| 网页与统一外壳 | `web/` | 三个 tab 的统一入口，四端共用一份外壳 |
| 桥接包 | `music/cloudmusic-car/lunastub/` | 车机助手与车上音源之间的桥（18764 / 18767） |
| 手机端 | `phone/android/`、`phone/ios/` | 只做 WebView 外壳，不翻译协议、不重画界面 |

**下游（运行时对接谁）**

```
18766  注入 dex（车控 + 网关）  ← 手机 / 浏览器只连这一个口
  ├─ /music/*  /api/*  → 18765 第三方云音乐车机版
  │                    → 18764 桥接包（官方网易云模式，与 18765 互斥）
  └─ /dvr/*            → 18767 桥接包 DvrSvc（行车记录仪）
```

### 云音乐端的来源与许可

- 上游链：`xuqian-git/cloudmusic-car` ← `missuo/kumone`，两个项目都是 **LGPL-3.0** 开源。

- 应用图标沿用上游仓库自带资源，没有另行重绘，也没有拿官方客户端图标顶替。

## 环境

构建输入端（`make.py`）需要：

- Python 3.8+（只用标准库，无第三方依赖）
- JDK 17
- Android SDK：`build-tools 34.0.0` + `platforms/android-35`
- apktool 2.11.1，放到 `patch/apktool.jar`（体积大，不在仓库里，自行下载）

音乐端与手机端走 Gradle wrapper（8.14.5 / AGP 8.7.3 / Kotlin 2.0.21），首次构建需联网拉依赖。
iOS 需 macOS + Xcode + XcodeGen，或直接走仓库内的 GitHub Actions 云构建。

路径不写死在代码里，按需提供：

```bash
# 方式一：工程根建 local.env（不入库）
JB=<jdk-17 目录>
BT=<build-tools 目录>
ANDROID_JAR=<sdk>/platforms/android-35/android.jar

# 方式二：scripts/config.local.sh（不入库，脚本用）
```

缺配置会直接报出缺哪一项。脱壳另需 root 设备 + frida-server，装包另需 adb。

## 端口

| 端口 | 谁在提供 | 什么时候在 |
|---|---|---|
| **18766** | 助手（网关） | 常驻 |
| **18765** | 第三方网易云车机版 | 它在跑时 |
| **18764** | 桥接包 | 官方音源模式 |
| **18767** | 桥接包 `DvrSvc` | 常驻 |

手机和浏览器只连 18766，页面上切三个 tab：车机控制 / 音乐控制 / 行车记录仪。18764 与 18765 互斥。
