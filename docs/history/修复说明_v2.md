# 车机助手 V18.49 闪退修复说明（v2）

## 一、闪退的真正原因

上一版（`车机助手_V18.49_mod.apk`）漏掉了整份**库 dex**。

原包是百度加固，其文件结构是：

| 位置 | 内容 |
|---|---|
| `classes.dex`（1.6MB） | **库 dex**：androidx 694 类、com.google 508 类、android/support 61 类、加固壳 32 类 |
| `assets/baiduprotect1.jar` 等 | **业务代码**（加密，运行时解密加载） |

脱壳工具只 dump 了业务代码（那 3440 个类），所以脱壳源码里**一个 androidx 类都没有**。
上一版直接用它重打包，导致：

- `MainActivity extends Landroidx/appcompat/app/r;` → 父类找不到
- `NaviApplication.applySavedTheme()` 调用 `androidx.appcompat.app.w.j()` → 类找不到
- 清单里的 `androidx.startup.InitializationProvider` 及其 Initializer 也都在库 dex 里

启动瞬间即 `NoClassDefFoundError`，表现为点开图标立刻闪退，且发生在崩溃捕获安装之前，所以没有日志。

实测数据：修复前 dex 中**被引用但未定义的非系统类 535 个，其中 androidx 191 个，而 dex 内 androidx 定义数 = 0**。

## 二、修复做法

把原包 `classes.dex` **原样**作为 `classes4.dex` 追加进新包（字节不动）。

这样做的好处：

- 库版本与业务代码 100% 匹配（本来就是同一个 APK 混淆出来的）
- 不重编译库 dex，无引入新问题的风险
- 已确认两侧类名**零冲突**（库 1346 类 vs 业务 3440 类，交集 0）
- 库 dex 里残留的 32 个 `com/sagittarius` 加固壳类经检查**被其他类引用次数为 0**，属死代码，不会执行

## 三、修复后验证

| 项目 | 结果 |
|---|---|
| dex 数量 | 4 个：classes / 2 / 3 / 4 |
| 定义类总数 | 4786 |
| 被引用未定义 androidx | 191 → **1**（仅 `androidx.exifinterface`，图片裁剪才用） |
| 被引用未定义非系统类 | 535 → **343**（剩余为 `miui/*`、`org/conscrypt`、`org/bouncycastle`、`org/eclipse/paho` 等运行期可选依赖，原包同样如此） |
| MainActivity 父类 `androidx/appcompat/app/r` | 已定义 |
| 清单 42 个组件类 | 全部存在 |
| 签名 | v2 + v3 通过 |
| 对齐 | `zipalign -c -p 4` 通过，so 4096 对齐且未压缩 |
| 四项修改补丁 | 全部保留（VIN 固定 / VIP 恒真 / 断网 / 签名校验跳过） |
| 加固残留 | 0 |

## 四、安装

- 与上一版**同签名同 versionCode**，可以直接覆盖安装，配置会保留
- 若车机上还有**原版**，必须先卸载（签名不同，无法覆盖）
- 装好后如仍闪退，崩溃日志在 `/sdcard/navitool/logs/`；有 adb 的话直接 `adb logcat -b crash -d`

## 五、复现命令

```
# 1. 解包 + 反汇编 + 打补丁（同上一版）
python patch_smali.py apk_decoded

# 2. 重新打包
java -jar apktool.jar b apk_decoded -o unsigned.apk

# 3. 补回库 dex  ★关键新增步骤★
python add_libdex.py 车机助手正式版_V18.49_sign.apk unsigned.apk merged.apk

# 4. 对齐 + 签名
zipalign -f -p 4 merged.apk aligned.apk
java -jar apksigner.jar sign --ks debug.keystore --ks-pass pass:android \
     --ks-key-alias debugkey --key-pass pass:android \
     --min-sdk-version 26 --v1-signing-enabled true --v2-signing-enabled true \
     --out 车机助手_V18.49_mod_v2.apk aligned.apk
```
