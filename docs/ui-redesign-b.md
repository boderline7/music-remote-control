# 外壳与各 Web 页面改版方案（方向 B：石墨工程感）

状态：待确认 · 未实施
范围：`web/shell/` 与四个 Web 页面（`web/pages/car.html`、`remote.html`、`remote_lunastub.html`、`dvr.html`）的**样式与文案**。
不改：端口、协议、接口、桥接 / 注入逻辑、补丁表、任何 Java / Kotlin 代码。

## 1. 方向定义

车机场景，前装原厂的克制感。去掉胶囊、色块、发光；用 1px 描边、分区、字重和单一琥珀强调区分层级。数字用等宽，状态用色语义固定。

产品性格一句话：**冷静、可读、像原厂仪表，不像玩具。**

## 2. 设计令牌（唯一来源，替换全部硬编码色值）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#121316` | 页面 / 外壳底色 |
| `--surface` | `#1a1c1f` | 卡片、抽屉、面板 |
| `--surface-2` | `#202226` | 输入框、次级块、按下态 |
| `--line` | `#2b2e33` | 所有 1px 描边、分隔线 |
| `--line-strong` | `#3a3e44` | 聚焦 / 选中描边 |
| `--text` | `#e8e9ea` | 主文字 |
| `--text-2` | `#9a9ea4` | 次级说明 |
| `--text-3` | `#6f747a` | 版本号、注释、禁用 |
| `--accent` | `#d9a441` | 唯一强调：选中、主操作、当前页 |
| `--ok` | `#4fbf7f` | 在线状态点 |
| `--off` | `#6f747a` | 离线状态点（**灰，不用红**） |
| `--danger` | `#e05a4f` | 仅破坏性操作（清空记录等） |

- 圆角：容器 / 卡片 `8px`，小控件 `4px`。不再出现 11/12/18px。
- 间距：4 / 8 / 12 / 16 / 24，禁止 7、9、11、13 这类散值。
- 字号：11（角标）/ 12（说明）/ 13（控件）/ 14（正文）/ 16（标题）。禁止 13.5、15 这类半档。
- 字体：系统无衬线；温度、挡位、速度、版本号用等宽 `ui-monospace` + `font-variant-numeric: tabular-nums`。
- 阴影：只允许抽屉用一层 `0 -8px 24px rgba(0,0,0,.45)`；其余一律无阴影。
- 渐变、发光、玻璃模糊：全部移除。

## 3. 组件规格

### 3.1 Tab 切换（`_shell.body.html` 三颗按钮）
- 去掉胶囊背景和描边，改为等分三列的下划线 tab。
- 选中：`--text` + 600 字重 + 2px 底部实线 `--accent`；未选中：`--text-2`，无底线。
- tab 下方一条 1px `--line` 贯穿整宽，作为分区线。
- 状态点保留（5px），位置改为文字左侧；`on` 绿、`off` 灰、warn 琥珀。
- 高度 44px，点击热区不变。

### 3.2 底部状态条
- 底色 `--bg`，顶部 1px `--line`，字号 12，正文 `--text-2`。
- 状态点：在线绿、离线灰、警告琥珀。
- 版本号 `--text-3`，等宽。
- 两个圆形按钮保留功能，改为 34px 方形 4px 圆角 ghost 描边（`--line`），图标 17px、线宽 1.8。

### 3.3 卡片 / 控制块（车控、音乐、记录仪通用）
- `--surface` 底 + 1px `--line` + 8px 圆角，内边距 12。
- 标题 13px `--text`，数值 16px 等宽 `--text`，单位 11px `--text-2`。
- 选中态的开关：`--accent` 描边 + `--accent` 图标，**不做实心填充**。
- 滑杆：轨道 `--surface-2`，填充 `--accent`，滑块 14px 正方形 2px 圆角（工程感，不用圆点）。

### 3.4 失败 / 未检测到覆盖层（`sfail`）
- 底色 `--bg`，标题 15px `--text`，说明 13px `--text-2`。
- 单个 ghost 按钮（`--line` 描边，`--accent` 文字）。
- 离线不再使用红色，统一灰 + 文案「未检测到」，与状态点语义一致。

### 3.5 设置 / 诊断抽屉
- 8px 上圆角，`--surface` 底，`--line` 分隔，去掉大阴影只留一层。
- 分段按钮：选中 `--surface-2` + `--line-strong` 描边 + `--text`；未选中透明。
- 日志文本：`--bg` 底 + `--line` 描边，11px 等宽 `--text-2`。
- 主操作（生成 / 连接）用 `--accent` 描边；清空等破坏操作才用 `--danger`。

## 5. 交付与验证

1. 本地起 18766/18765/18764/18767 四个端口，浏览器 1280×720 与 390×844 各截图一遍（四个 tab 状态、诊断抽屉、失败态）。
2. 对照检查：无渐变 / 无发光 / 无 emoji / 所有间距落在 4 的倍数 / 对比度 ≥ 4.5:1（正文）。
3. 重出包：车机助手、音乐 App、桥接包各一份；`amd64` 侧不涉及。
4. 装车验证顺序：先装桥接包（18764 + 18767）→ 音乐 App（18765）→ 车机助手（18766）。
5. 回滚：单次提交，`git revert` 即恢复旧皮肤，无数据 / 配置迁移。

## 6. 风险

- 四个页面各自内联 CSS 约 100–107KB，存在同名类（`.card`、`.row`、`.btn`）冲突风险；改版以页面级作用域前缀隔离。
- 页面资源打包在 APK assets 内，**改完必须重出包**才能上车，不能热推。
- 深色为主，日间强光下的可读性未在实车验证；预留：若需要，后续加一套 `prefers-color-scheme: light` 的同令牌浅色值，不动结构。
- 本次不做「三模块独立断开、不自动重试」的逻辑改动，仅预留灰色离线样式；该逻辑另列一项实施。
