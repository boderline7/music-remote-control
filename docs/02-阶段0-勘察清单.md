## F. 需要改/新增的文件（勘察后填）

```
修改：
  （等勘察结果）
新增：
  RemoteServer.java          WebSocket 服务端 + 连接管理
  RemoteProtocolHandler.java 消息分发 + 认证
  PlayerBridge.java          播放器薄适配层（唯一碰原播放器的地方）
  PairingStore.java          Token 哈希、设备列表
  NsdRegistrar.java          mDNS 注册
```

原则：**`PlayerBridge` 是唯一直接调用原播放器代码的类**。以后播放器换实现只改这一个文件，遥控链路不动。
