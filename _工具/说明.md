# 工具链环境（bash / Git Bash 下 source 本文件）

> 注：两端现在都走 Gradle 构建（`JAVA_HOME` 指向本机完整 JDK，`local.properties` 指向本机 Android SDK），
> 本文件下面记的是早期手工打包那套，留作备用。

## 网页遥控相关的自检脚本

| 脚本 | 作用 |
|---|---|
| `_工具/test_remote_page.mjs` | `node _工具/test_remote_page.mjs`：用最小 DOM + WebSocket 模拟跑 `assets/remote.html`，验证配对、播控、爱心、搜索、资料库、分页、断线重连发出的指令与界面文字 |
| `_工具/make_preview.py` | `python _工具/make_preview.py`：在系统临时目录生成 `carremote-preview/*.html`（塞了假数据），再用 Edge 无头截图看真实排版 |
| `_工具/check_mdns.py` | `python _工具/check_mdns.py`：逐字节校验 mDNS 应答/宣告报文（多问题包、NSEC、压缩指针），并检查保活节奏 —— 重播间隔必须小于 TTL 的一半，否则对端缓存会先过期 |

## 路径

| 用途 | 路径 |
|---|---|
| JDK（**完整版，含 javac**） | `~/.workbuddy/binaries/jdk/jdk-17.0.20.1+1` |
| 编译用 android.jar（API 35） | `~/.workbuddy/binaries/android/android-35/android.jar` |
| build-tools（aapt2 / d8 / zipalign / apksigner，34） | `~/.workbuddy/binaries/android/android-14` |
| 签名库 | `keystore/<你的签名库>.jks`（alias / 口令自己设，`CR_KS_PASS` 从环境变量读） |

注意别拿 **jre 版** JDK（没有 javac）来编译，只能跑不能编。

## 变量

`env.sh` 导出：

- `CR_JDK` / `CR_JAVAC` / `CR_JAVA`
- `CR_AJAR` — 编译 classpath 用的 android.jar
- `CR_BT` — build-tools 目录
- `CR_KS` / `CR_KS_PASS` / `CR_KS_ALIAS`
- `PATH` 前置 JDK bin 与 build-tools
